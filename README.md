# Vita-Vibecoded-Games
Here are a few games I asked Claude to remake on the PSVita. Everything is completely vibecoded.

## Games

- **Survivor.io Vita** – offline horde-survival action
- **AC-130 Spectre** – 3D thermal-view gunship shooter
- **Stairway to Heaven** – round-based zombies FPS
- **Quilt Cats** – cozy cat logic puzzle

Install any of them by copying the `.vpk` from [`downloads/`](downloads/) to your Vita and installing it with VitaShell.

## Website

The `index.html` / `games/` pages are a GitHub Pages site showcasing each game. In the repo settings, go to Pages and set the source to "Deploy from a branch", branch `main`, folder `/ (root)`.
